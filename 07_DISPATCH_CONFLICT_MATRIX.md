# 07_DISPATCH_CONFLICT_MATRIX

**Program:** Dispatch  
**Owner:** Mike Zachary / Level 1 Transport  
**Status:** Source of Truth / Governance Stack  
**Rule:** No amendments. Rewrite and replace the governing file when doctrine changes.  


## 1. Purpose

Define mandatory stop conditions and Conflict Notice triggers for every Dispatch agent and build.

## 2. Universal Conflict Triggers

Stop and produce Conflict Notice if work requires:

- inventing facts
- unsupported eligibility
- signature or certification
- submission
- package approval
- rate decision
- compliance decision
- legal sufficiency decision
- doctrine change
- architecture change
- role-boundary change
- draft promotion into Library truth
- Library/Archive blur
- research-as-truth
- public exposure without approved authentication
- new agents without approval
- new workflows without approval
- Manager bypass
- Mike bypass

## 3. Agent-Specific Conflict Triggers

| Agent | Conflict Triggers |
|---|---|
| Manager | missing decision owner, conflicting recommendations, role overlap, architecture change |
| Publisher | missing source, signature required, certification required, unsupported claim, eligibility unclear |
| Library | unapproved asset, conflicting versions, expired asset, missing approval trail |
| Archive | active draft marked final, missing decision record, missing submission record |
| Intelligence | source ambiguity, contradictory requirements, missing evidence, research treated as truth |
| Dispatcher | unknown rate, unknown broker terms, unsafe route, unsupported load facts |
| Portal | unauthorized visibility, data ownership confusion, internal public exposure |
| Automation | missing trigger, missing owner, external action without approval |
| Acquisition | unauthorized source, broken source chain, missing source metadata |
| Processing / Rules | missing rule, contradictory rule, attempted doctrine change |
| Refinement Analyst | role overlap, boundary violation, Constitution violation, authority creep |
