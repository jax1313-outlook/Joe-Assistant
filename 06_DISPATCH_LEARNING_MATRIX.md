# 06_DISPATCH_LEARNING_MATRIX

**Program:** Dispatch  
**Owner:** Mike Zachary / Level 1 Transport  
**Status:** Source of Truth / Governance Stack  
**Rule:** No amendments. Rewrite and replace the governing file when doctrine changes.  


## 1. Purpose

Define what agents may learn from, what they may not learn from, what can become memory, what can become truth, and what remains knowledge only.

## 2. Approved Learning Sources

Agents may learn from:

- approved Library assets
- Mike-approved final outputs
- accepted edits
- rejected drafts
- final archived packets
- decision logs
- walkthrough reports
- test results
- completed requirement matrices
- approved templates
- approved rate sheets
- sealed compliance records
- submitted package records
- approved form-fill guides

## 3. Non-Authoritative Inputs

Agents may not treat these as truth:

- Research Scout reports
- public examples
- internet content
- third-party templates
- AI drafts
- unreviewed packets
- old packets
- expired forms
- unapproved notes
- sample letters

## 4. Agent Learning Boundaries

| Agent | May Learn From | May Not Treat As Truth |
|---|---|---|
| Manager | decision logs, conflict outcomes, approved routing patterns | unapproved priorities, AI preference |
| Publisher | approved packets, accepted edits, rejected drafts, templates | research, samples, unapproved wording |
| Library | approved storage decisions, version history, review dates | unapproved drafts, Research Library knowledge |
| Archive | final package history, retrieval patterns | active workspace drafts |
| Intelligence | approved matrices, final opportunity reviews | research-as-truth, unsupported assumptions |
| Dispatcher | approved/rejected load outcomes, route/position history | broker claims without source |
| Portal | approved display/card patterns | raw data ownership assumptions |
| Automation | approved workflow execution patterns | self-triggered events |
| Acquisition | source capture patterns | interpreted relevance |
| Processing / Rules | approved deterministic rules | new doctrine inferred from data |
| Refinement Analyst | accepted/rejected refinement cards, drift outcomes | personal preference as doctrine |

## 5. Memory Rule

Learning improves recommendations. Learning does not create authority.
