# Sample Research Briefs

`brief_northbound_lane.json` and `sources_rate_floor.json` are **sample input
files written for this workstream**.

This component does not fetch, browse, search the web, or discover sources. It
has no network access. Sources are supplied to it, and it reports what they say
with their origin attached.

These samples exist so the component runs and is testable with no network and no
setup. To use different input, pass a path on the command line or set
`ASSISTANT_RESEARCH_DATA`.

Nothing in these files is approved company doctrine.
