# Sample Corpus

These documents exist so Assistant Library runs with no setup and so its tests
have something real to read.

They are **samples written for this workstream**. They are not approved company
facts, not doctrine, and not a copy of the real Company Library. Nothing here
should be treated as authoritative.

To point the component at a real library, pass `--root` or set
`ASSISTANT_LIBRARY_ROOT`. The component still only reads.
