# Appointment Windows

An appointment window is the period a facility has agreed to work the load.

## Confirmed versus stated

A window is confirmed when the facility has acknowledged it. A window a broker
mentioned is stated, not confirmed. The difference decides whether a driver
should leave early.

## Recording a window

Record the window, who confirmed it, and when. An unconfirmed window is recorded
as unconfirmed rather than left blank.
