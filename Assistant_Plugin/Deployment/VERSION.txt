WHAT CHANGED SINCE 1.0.0

  The package identity. 1.0.0 was built before the program was renamed to JOE
  and shipped assistant_main.py and START_ASSISTANT.cmd. It kept that name
  while the source moved on without it, so anyone deploying from it got a
  build in which mail, calendar and contacts all refused - and its bundled
  proof suite reported 24 of 24 while doing so.

  Mailbox discovery. The registry was never discovered, so every mail,
  calendar and contacts question refused regardless of what the mailboxes
  held. Fixed.

  One-sentence answers. JOE speaks one sentence and holds the rest until asked
  for it. File paths are never read aloud.

  Claude as a reasoning provider, with fast mode. Copilot answered in 6.6 and
  9.9 seconds on this machine, which is too slow to talk to while driving.

  The proof suite. Seven steps could report PASS while the thing they
  described was broken; all seven now fail when it is. See
  docs/PROOF_AUDIT_v1.md.
